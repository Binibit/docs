## What is the Agent Hive

The **Agent Hive** is the registry of all agents and all pools. Three layers, hive principle:

```
QUEENS (3)     ← Strategic layer: ecosystem-wide coordination,
                  cross-pool liquidity, risk control,
                  referral intelligence

       │ signals
       ▼

SCOUTS (2)     ← Tactical layer: token analysis, risk scoring,
                  rug detection, signal generation

       │ targets
       ▼

WORKERS (N)    ← Execution layer: one per Agent Token,
                  manages the Agent Pool, monitors trades,
                  distributes incentives

SWARM          ← Active runtime: the subset of Workers currently
                  deployed and processing in the field.
                  Swarm ⊆ Hive.
```

Override chain: **Queen > Scout > Worker**. All overrides logged on-chain.
