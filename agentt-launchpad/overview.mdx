## What is AgentT Launchpad

Create an Agent Token in one tap. The **Agent Hive** picks it up automatically:

1. Spawner deploys an ERC-20 (your Agent Token)
2. An **Agent Worker** is assigned to your token and joins the active **Swarm**
3. An **Agent Pool** auto-lists on BaiDEX (wBINI or USBI side)
4. **Agent Scouts** notice the new token and report to the **Agent Queens**
5. Queens factor it into ecosystem-wide strategy

No manual management. The hive runs the rest.
