## Overview

The Binibit public API exposes four REST endpoints under the `/getcoingecko/` namespace. They follow the **CoinGecko Integration API Standards v8** for centralized spot exchanges.

| Method | Path | Purpose |
|---|---|---|
| `GET` | [`/tickers`](/api-reference/tickers) | 24-hour stats for every active pair |
| `GET` | [`/orderbook`](/api-reference/orderbook) | Order book depth for one pair |
| `GET` | [`/historical_trades`](/api-reference/historical-trades) | Recent trades for one pair |
| `GET` | [`/asset`](/api-reference/asset) | Asset metadata |

## Base URL

```
https://internal-api.binibit.com/api/marketdata/getcoingecko
```

## Authentication

None. See [Authentication](/general/authentication).

## Rate limits

60 requests per minute per IP. See [Rate Limits](/general/rate-limits).

## Conventions

- All requests are `GET` with query parameters
- All responses are JSON
- All numeric values are decimals (prices, volumes) or integers (timestamps in milliseconds, IDs)
- All timestamps are Unix epoch milliseconds — see [Timestamps](/general/timestamps)
- Errors follow a unified envelope — see [Errors](/general/errors)
