## What is BaiDEX

BaiDEX is a Uniswap V3-compatible AMM running on BiniChain, with a **custom fee router** and an **agent layer** that manages every Agent Token pool.

The DEX where every token has an agent brain.

## Fee structure

```
Total swap fee:  1.00%  (100 BPS)
├── 0.50%  LP providers       (50 BPS)
├── 0.25%  Burned permanently (25 BPS) — deflationary
└── 0.25%  Referrer / treasury (25 BPS)
```
