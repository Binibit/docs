## What is BINI

BINI is the native token of the Binibit ecosystem. It is:

- **Gas** on BiniChain (every transaction pays BINI)
- **Trading reference** on Binibit Exchange (BINI/USDT pair)
- **Staking asset** on Binibit Exchange (160% APR, R0-R8 referrals)
- **Fee currency** for Agent Token spawn, lottery tickets, DEX referrer rewards
- **LP asset** as wBINI on BaiDEX
