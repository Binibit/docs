## What is BiniChain

BiniChain is an **EVM-compatible Layer 1** with **BINI** as the native gas token. It hosts BaiDEX, AgentT Launchpad, the Agent Hive, and the bridges that connect on-chain assets to the off-chain Bini App economy.

| | |
|---|---|
| Type | EVM L1 |
| Native gas | BINI |
| RPC | https://rpc.binibit.com |
| Block explorer | https://scan.binibit.com |
