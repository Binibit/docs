## v1.0 — 2026-04-28

Initial public release of the Spot Market API.

### Endpoints

- `GET /tickers` — 24-hour stats for every active pair
- `GET /orderbook` — order book depth per pair
- `GET /historical_trades` — recent trades per pair
- `GET /asset` — asset metadata

### Conventions

- All timestamps in milliseconds (Unix epoch)
- All `type` values lowercase (`"buy"` / `"sell"`)
- `historical_trades` response shape: `{ buy: [...], sell: [...] }`
- Schema aligns with CoinGecko Integration API Standards v8 so aggregators can ingest without translation
