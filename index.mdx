## Quick start

Fetch live ticker data for every active trading pair:

```bash
curl https://internal-api.binibit.com/api/marketdata/getcoingecko/tickers
```

## Standards

The Binibit public API follows the **CoinGecko Integration API Standards v8** for centralized spot exchanges. Aggregators (CoinGecko, CoinMarketCap, DefiLlama) can integrate Binibit market data directly with no schema translation.
