## Quick start

Fetch live ticker data for every active trading pair:

```bash
curl https://internal-api.binibit.com/api/marketdata/getcoingecko/tickers
```

## Highlights

- **Public.** No authentication, no API key.
- **REST + JSON.** Standard HTTP, predictable schemas.
- **Real-time.** Tickers refresh every few seconds.
- **Rate-limited fairly.** 60 requests per minute per IP by default; aggregators and integrators get whitelisted on request.
