## Quick start

Fetch the latest ticker for `ETH_BTC`:

```bash
curl "https://public-api.binibit.com/api/tickers?currencyPairCode=ETH_BTC"
```

## Highlights

- **Public.** No authentication, no API key.
- **REST + JSON.** Standard HTTP, predictable schemas.
- **Real-time.** Tickers refresh every few seconds.
- **Two API surfaces.** A primary `public-api.binibit.com` and an aggregator-spec namespace at `internal-api.binibit.com/.../getcoingecko/*` for CoinGecko / CoinMarketCap-style integrations.
- **Rate-limited fairly.** Aggregators and integrators get whitelisted on request — see [Rate Limits](/general/rate-limits).

## Trading and wallets

The trading API (create orders, cancel orders, list user orders, deposits, withdrawals) is part of `public-api.binibit.com`. It is documented at `https://public-api.binibit.com/swagger/` and uses HMAC-SHA256 request signing — see the [Roadmap](/changelog#roadmap) for documentation status.
