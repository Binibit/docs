## For data aggregators

If you are integrating Binibit into a data aggregator (CoinGecko, CoinMarketCap, DefiLlama, CryptoCompare, Kaiko, etc.):

- Email [api@binibit.com](mailto:api@binibit.com) with subject `[Aggregator: <name>]`
- Include your IP range or CIDR for whitelisting
- Mention expected request volume

We can provide:

- Unlimited or very high rate limits via static IP whitelist
- Direct access to the data engineering team
- Pre-release notice on schema changes
