## Purpose

This page exists to satisfy the CoinGecko Integration requirement that **API data must match what is shown on the trading interface**.

It displays values fetched directly from the public `/tickers` endpoint, so anyone — CoinGecko reviewers, CoinMarketCap reviewers, end users — can independently verify Binibit market data.

## Reproduce locally

```bash
curl -s https://internal-api.binibit.com/api/marketdata/getcoingecko/tickers \
  | jq -r '.[] | [.ticker_id, .last_price, .base_volume, .target_volume, .bid, .ask] | @tsv' \
  | column -t
```

## For aggregator reviewers

If you are reviewing Binibit for listing on CoinGecko, CoinMarketCap, DefiLlama, or similar:

- The `/tickers` endpoint is the source of truth for last prices and 24h volumes
- Click any "open" link above to see the same numbers on the live trading interface
- Email [api@binibit.com](mailto:api@binibit.com) for IP whitelisting and elevated rate limits during your review
